# R332 Checklist — `pvpgn-config` CLI tool

## Goal
Provide a standalone CLI tool for operators to validate config files, inspect
the effective (post-env-override) configuration, and browse the config schema
without starting the full server.

## Steps

- [x] **Create `src/v3/app/pvpgn-config/main.cpp`**
  - `--validate <file>`: loads config via `load_server_config()`, reports
    errors, exits 0 on success / 1 on error.
  - `--print-effective <file>`: loads config + env overrides, prints the
    effective config as TOML with secrets redacted (`operator<<` prints `***`).
  - `--print-schema`: prints a full Markdown table of all config keys,
    types, defaults, and descriptions for all 20 TOML sections.
  - `--help` / `-h`: prints usage.

- [x] **Create `src/v3/app/pvpgn-config/CMakeLists.txt`**
  - Defines `pvpgn_config_tool` executable.
  - Links against `pvpgn_infra_config` and `pvpgn_core`.
  - Applies `pvpgn_v3_apply_flags()` for C++20 + warning flags.
  - Installs to `${BIN_INSTALL_DIR}`.

- [x] **Update `src/v3/CMakeLists.txt`**
  - Added `add_subdirectory(app/pvpgn-config)` after `app/pvpgn-migrate`.

## Notes
- The tool has no Boost dependency — it only needs `pvpgn_infra_config` and
  `pvpgn_core`, so it is always built regardless of `PVPGN_V3_WITH_BOOST`.
- Secret fields are automatically redacted in `--print-effective` output
  because `operator<<` on `core::Secret<T>` always prints `"***"`.
- The `--print-schema` output is the source of truth for `docs/config-reference.md`
  (regenerated by `scripts/dev/gen-config-docs.sh`).
